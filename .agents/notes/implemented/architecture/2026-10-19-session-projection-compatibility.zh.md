# Agent Note: 已弃用的投影注册兼容接口

Status: implemented

[English](2026-10-19-session-projection-compatibility.md) | 中文

## Problem

现有外部插件使用投影注册返回的 disposer，并通过 registry 读取状态。异步保留读取句柄改善了获取和清理所有权，但删除这些运行时操作会迫使彼此无关的插件一起迁移。

## Decision

[保留读取句柄的决策](2026-10-12-session-projection-registration-handles.zh.md)仍是常规 API。注册返回值兼容 Promise 且可调用：等待它得到句柄，调用它保留旧的释放操作。这个可调用值就是原有 Cordis effect disposer，使组合 effect 能接管其所有权并控制释放顺序。按键读取作为已弃用的运行时 API 保留，返回类型为 `unknown`。TypeScript 消费方仍需迁移声明；旧宿主状态映射和泛型签名不再恢复。每个键的首次按键读取通过 `ctx.logger.warn` 输出一次弃用警告；该逐键状态归各 registry 实例所有，不归进程全局对象所有。注册及调用其返回值不产生警告：被忽略的返回值与稍后才等待的返回值无法区分，检测旧式注册需要一个启动截止点。

定义安装保持同步，句柄交付保持异步，与保留读取句柄的决策完全一致。注册错误使返回值拒绝。旧插件可能从不观察返回值；未处理的拒绝会结束 `dsh` 进程，而旧 API 只会令该插件激活失败。当前轮次结束前没有调用方观察该拒绝时，registry 通过调用方插件的 logger 记录它，并让插件保持激活但缺少该单元；owner 已不在加载或激活状态的拒绝会被丢弃，因为已没有人能使用其句柄。被观察的拒绝仍由调用方负责。

这部分取代了先前决策中无条件迁移的要求。保留的句柄仍可在释放后折叠事件，按键读取仍在最后一次释放后失去访问，新代码使用私有句柄或所属领域服务。同步 `try/catch` 无法捕获异步获取失败。兼容性依赖当前同步安装定义的实现；引入异步准备时，需要重新处理在激活前读取的旧消费方，不能静默返回不完整状态。

## Alternatives considered

**要求所有外部插件立即迁移。** 即使插件只在初始化期间注册并在激活后读取，也会让保留读取句柄的变化成为整个部署需要协调的事项。

**返回 disposer 的新包装函数。** Cordis 组合按原始返回值身份接管 effect。包装函数会让原注册继续独立归属，从而使 owner 卸载在组合清理结束前释放它。

**自动延后所有 effect 或事件监听器。** 这些操作已有同步消费方和初始化期间的观察方。兼容要求属于投影获取；改变无关 effect 的时机会造成更大范围的迁移。

## Consequences

旧插件可以独立迁移，新代码保留显式异步获取。兼容层保留同步运行时组合和按键读取的逐键一次诊断。异步函数或异步生成器会把可调用的 thenable 吸收为句柄，因此旧的异步 return/yield 组合仍需迁移。仅接受原生 Promise 的消费方使用 `Promise.resolve(registration)`。定向测试覆盖现代错误恢复、被忽略拒绝的日志记录、owner 卸载后的静默拒绝、可调用与组合释放、获取期间 owner 卸载，以及逐 registry 的警告所有权。真实 Loader 子进程通过包入口运行保持旧写法的插件，并验证读取结果和按键读取警告。
