  - button "自動認可レビューを表示": 自動認可レビュー
  - text: 実験的 「自動認可レビュー」アクセスモードを追加します。アクセスモードメニューで選択するか /permission auto を入力すると、現在のセッションに適用されます。各ツール呼び出しの前に、モデルリクエストがその呼び出しをあなたの依頼内容と照らし合わせて確認します。許可された呼び出しはサンドボックスなしの完全なアクセス権で即座に実行され、拒否された呼び出しはあなたの承認を待ちます。PTC モードでは、プログラムが行うツール呼び出しのみがレビューされ、プログラム自体のファイル操作やプロセス操作はレビューされません。レビューは安全でない操作を許可したり、有用な作業を拒否したりすることがあります。プラグインをオフにすると、開いている「自動認可レビュー」セッションは「フルアクセス」に切り替わり、保存された「自動認可レビュー」セッションはプラグインが有効な間のみ再び開けます。
