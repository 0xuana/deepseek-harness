# CUA 相对坐标使用 0～999

[English](guide.md) | 中文

## 变更

`cua` 工具和应用或窗口对象方法在 `relative: true` 时接受 0～999 的整数，原范围为 0～1000。坐标按窗口尺寸缩放前的除数由 1000 改为 999，上限坐标仍位于窗口内部。这影响 `click`、`hover`、`scroll` 和 `drag` 的起终点。绝对截图像素和 AX 元素编号保持原有行为。

## 迁移

1. 更新生成相对坐标的脚本和提示。对于 0～1 的归一化比例 `r`，使用 `Math.round(r * 999)`。已保存的旧坐标使用 `Math.round(oldValue * 999 / 1000)` 转换；旧端点 1000 转换为 999。
2. 读取新的窗口状态后，使用 0～999 的整数坐标调用相应动作，再读取新状态验证结果。相对坐标为 1000、负数或小数时，会在原生输入前被拒绝。
